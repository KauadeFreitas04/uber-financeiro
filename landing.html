Dúvidas

Perguntas frequentes

Precisa instalar alguma coisa?
Não! O FinanceDriver é um app web — você acessa pelo navegador do celular e instala como app na tela inicial com um clique. Sem Play Store, sem App Store.
Meus dados ficam seguros?
Sim! Seus dados são salvos no Firebase (Google) com criptografia. Apenas você tem acesso, através do seu login Google.
Funciona sem internet?
O app funciona offline para visualizar dados já carregados. Para salvar novos registros, é necessário conexão com a internet.
Posso usar em mais de um celular?
Sim! Como os dados ficam na nuvem, você pode acessar de qualquer dispositivo — celular, tablet ou computador — com o mesmo login Google.
Como funciona o pagamento?
Em breve integraremos o sistema de pagamento via PIX ou cartão. Por enquanto, o acesso está liberado gratuitamente para os primeiros usuários!
